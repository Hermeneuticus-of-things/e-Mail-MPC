# Project instructions

## Application UI

- This repository has adopted Ionuț Application Design Language: **yes**. For every eMail MPC application task—feature implementation, behavior, interaction, UI design, review, or redesign—load and follow [`.agents/skills/ionut-application-design-language/SKILL.md`](.agents/skills/ionut-application-design-language/SKILL.md). Read its complete source, [`IONUT_APPLICATION_DESIGN_LANGUAGE.md`](IONUT_APPLICATION_DESIGN_LANGUAGE.md), before changing behavior or interfaces governed by it. The standalone skill copy is [`IONUT_APPLICATION_DESIGN_LANGUAGE.SKILL.md`](IONUT_APPLICATION_DESIGN_LANGUAGE.SKILL.md); if the runtime cannot load project skills, read that copy directly. The rules cover UX and UI and are mandatory, not optional inspiration.
- Keep reading and composing email in the foreground. In the compose window, focus the message body; keep supporting controls available, compact, and quiet.
- Use compact dropdowns for enumerated values and resizable vector-scalable layouts. Preserve every implemented feature and command; organize full menus into clear categories instead of deleting or flattening them for visual simplicity. Follow the documented accessibility and sizing requirements and use native email workflows.
