# Project instructions

## Application UI

- For every design, implementation, or redesign task involving the application's GUI, use [Hallmark](https://github.com/nutlope/hallmark) as the default design reference. Review its current guidance and relevant theme examples before changing the interface.
- Adapt Hallmark's emphasis on a distinctive visual identity, purposeful layouts, and avoiding generic AI-generated patterns to a native email client. Do not copy a theme or introduce website-specific structures that do not fit the app's workflows.
- Preserve existing functionality and make the user's email tasks the focus. Keep accessibility, keyboard use, readable contrast, focus visibility, and practical window sizing in view.
- Keep the working surface foregrounded; when composing, the message body is the primary writing surface and receives focus. Keep menus, buttons, and supporting controls available but compact and quiet, use dropdowns for value changes, and avoid oversized headings, buttons, icons, or other chrome.

## README

- For every new repository README or substantial README rewrite/redesign, invoke and use the installed Hallmark skill. Apply its project-specific visual direction and quality guidance to the repository homepage without inventing product claims, screenshots, metrics, or other evidence.
- Use the `beautify-github-readme` skill as the README-specific content and audit companion when available; follow its scope and approval rules.
